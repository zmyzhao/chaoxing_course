# 受监督视频学习辅助工具

本项目已实现首版 Node.js + Playwright 脚本。首次运行需要用户在专用 Edge 中手动登录并打开任意章节详情页；之后可复用独立浏览器配置中的登录状态。

目标是在 Windows 11 的专用 Edge 窗口中，辅助处理单门课程的章节视频与文件：从章节详情页开始，依目录顺序跳过已有绿色对勾的知识点/章节行；视频通过播放器进度条跳到接近末尾，再以静音、2× 播放至结束；PDF 文件通过页面快捷键滚动到末页。以对应目录行的绿色对勾确认完成。异常或超时会留下截图和记录。运行过程需要详细日志、最终报告以及 Ctrl+C 安全停止。

脚本只使用页面控件和键盘操作，不伪造学时、不调用隐藏完成接口或绕过验证。

## 使用方法

在本项目目录打开终端。直接运行 `npm start` 会打开使用 `data/edge-profile/` 的专用 Edge；在窗口中手动登录并打开任意章节详情页，脚本识别到左侧目录后自动开始。再次运行会复用此配置中的登录状态。

如果希望脚本先打开课程入口，复制 `config.example.json` 为本地的 `config.local.json`，在 `courseUrl` 中填入完整 HTTPS 课程链接；也可以运行 `npm start -- --url "<课程链接>"`。本地配置已排除在版本管理之外。不要把真实链接、令牌或账号密码写进 `config.example.json`。

首次验证可运行 `npm start -- --list`：它只读取目录和绿色对勾，不打开任务，也不播放视频。正式运行用 `npm start`。登录与进入详情页的等待时间默认 10 分钟，可在本地配置中调整。

运行时按目录顺序逐行处理。已有绿色对勾的行跳过；未完成行按页面顺序处理视频和可翻页 PDF 文件。视频先通过页面控件静音、选 2×，再点击进度条接近末尾的位置，播放至结束并核对该视频任务的完成标记。如果进度条没有跳到末尾，就以 2× 自然播放；若曾部分跳过内容，则先通过播放器回到开头。如果跳到末尾后任务仍未完成，也通过播放器界面回到开头，以 2× 完整播放一次。第二次仍未完成则截图记录并跳过该目录项。报告中的 `taskResults` 会记录最终采用的 `seek` 或 `natural` 方式及尝试结果。PDF 文件通过正常键盘操作滚动到末页，并核对文件任务的完成标记。下载附件（包括以 `.mp4` 命名但仅提供预览入口的附件）、测验和无法识别的其他任务记录后跳过。每个子任务的结果分别写入报告。全部可处理任务结束后最多等待 60 秒，以目录行出现绿色对勾为完成标准；未出现则记录 `row_unconfirmed` 并截图。橙色任务数字无需清零。

每次运行的 `events.jsonl`、`report.json`、`report.md` 和异常截图写入 `runs/<运行时间>/`。按 Ctrl+C 会暂停当前视频并写入报告；脚本结束后专用 Edge 窗口保留。
